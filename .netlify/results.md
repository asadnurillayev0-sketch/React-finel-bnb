The deployed site was showing a blank white page because Netlify had no build command or publish directory configured, and the repository had no `netlify.toml` to fill in that gap. As a result, the site was publishing the raw, unbuilt project source instead of a compiled application. The live page was loading `/src/main.jsx` directly in the browser — a file full of JSX syntax and bare package imports (like `react`) that only a build tool such as Vite can turn into code a browser can run. Since the browser couldn't execute that file, nothing ever rendered, leaving the root element empty.

A `netlify.toml` was added at the project root that tells Netlify to run `npm run build` (the existing Vite build script) and publish the resulting `dist` folder. This matches the app's existing setup — no source code changes were needed, since the React app itself, its client-side routing, and its connection to the external GraphQL backend were all verified to be working correctly. The next deploy will now compile the app properly before publishing it, so visiting the site should show the working Airbnb-clone homepage instead of a blank page.
